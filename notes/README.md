# Python & DSA Learning Repository

A comprehensive learning resource for Python programming and Data Structures & Algorithms, organized for progressive learning and easy reference.

## 📁 Repository Structure

```
practice-python/
├── 📚 fundamentals/           # Core Python concepts
├── 🏗️  oop/                   # Object-oriented programming
├── 🔧 advanced/               # Advanced Python topics
├── 🧪 testing/                # Testing frameworks and practices
├── 📊 data-structures/        # Data structures implementations
├── ⚡ algorithms/             # Algorithm implementations
├── 💻 coding-problems/        # Practice problems and solutions
├── 🌐 web-development/        # Web frameworks and tools
├── 📈 projects/               # Hands-on projects
├── 📝 notes/                  # Learning notes and cheat sheets
└── 🔄 legacy/                 # Old files (to be reorganized)
```

## 🎯 Learning Path

### Phase 1: Python Fundamentals
1. **fundamentals/** - Variables, data types, control flow, functions
2. **oop/** - Classes, objects, inheritance, polymorphism
3. **advanced/** - Decorators, generators, context managers

### Phase 2: Data Structures & Algorithms
4. **data-structures/** - Arrays, linked lists, trees, graphs
5. **algorithms/** - Sorting, searching, dynamic programming
6. **coding-problems/** - LeetCode, HackerRank style problems

### Phase 3: Practical Applications
7. **testing/** - Unit tests, BDD, test automation
8. **web-development/** - Flask, Django, FastAPI
9. **projects/** - Real-world applications

## 🚀 Quick Start

```bash
# Clone the repository
git clone <repository-url>
cd practice-python

# Set up virtual environment
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Start learning!
cd fundamentals/01-variables-and-types
python examples.py
```
