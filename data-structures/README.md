# Data Structures

Implementation and analysis of fundamental data structures used in computer science and software development.

## 📊 Topics Covered

### 01 - Arrays and Lists
- Dynamic arrays implementation
- Time and space complexity analysis
- Common operations and optimizations
- Python list internals

### 02 - Linked Lists
- Singly linked lists
- Doubly linked lists
- Circular linked lists
- Implementation from scratch

### 03 - Stacks and Queues
- Stack implementation (array and linked list)
- Queue implementation (array and linked list)
- Priority queues
- Deque (double-ended queue)

### 04 - Trees
- Binary trees
- Binary search trees (BST)
- AVL trees (self-balancing)
- Tree traversals (in-order, pre-order, post-order)

### 05 - Graphs
- Graph representation (adjacency list, matrix)
- Directed vs undirected graphs
- Weighted graphs
- Graph traversals (BFS, DFS)

### 06 - Hash Tables
- Hash function design
- Collision resolution strategies
- Load factor and rehashing
- Python dict implementation insights

### 07 - Heaps
- Min heap and max heap
- Heap operations (insert, delete, heapify)
- Priority queue implementation
- Heap sort algorithm

## 🎯 Learning Path

1. **Start with Arrays/Lists** - Most fundamental structure
2. **Move to Linked Lists** - Understand pointer manipulation  
3. **Learn Stacks/Queues** - Essential for algorithms
4. **Master Trees** - Critical for many algorithms
5. **Understand Graphs** - Complex but powerful
6. **Study Hash Tables** - Optimize lookup operations
7. **Implement Heaps** - Efficient priority management

## 📈 Complexity Cheat Sheet

| Operation | Array | Linked List | Stack | Queue | BST | Hash Table |
|-----------|-------|-------------|-------|-------|-----|------------|
| Access    | O(1)  | O(n)        | O(n)  | O(n)  | O(log n) | O(1) avg |
| Search    | O(n)  | O(n)        | O(n)  | O(n)  | O(log n) | O(1) avg |
| Insert    | O(n)  | O(1)        | O(1)  | O(1)  | O(log n) | O(1) avg |
| Delete    | O(n)  | O(1)        | O(1)  | O(1)  | O(log n) | O(1) avg |

## 🔗 Related Algorithms

Each data structure pairs with specific algorithms:
- **Arrays**: Binary search, sorting algorithms
- **Trees**: Tree traversals, tree balancing
- **Graphs**: Shortest path, minimum spanning tree
- **Heaps**: Heap sort, priority algorithms
